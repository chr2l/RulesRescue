# Historique du projet

Rules Rescue est né en octobre 2026, après la fermeture de rules.art, pour récupérer une collection de 250 cartes restée sur un ancien compte Argent X. Une grande partie du code a été écrite avec Claude Code ; chaque étape est une pull request qui explique ce qui change et comment ça a été testé.

| PR | Étape |
|---|---|
| (avant #1) | Script de récupération (`find`, `check`, `migrate`), explorateur et guide ; constat que les comptes Rules d'origine jamais migrés sont bloqués. |
| #1 | Médias HD via IPFS, mise en page façon profil Rules. |
| #2 | Outil `rtk` pour les sessions Claude Code. |
| #3 | Fusion automatique des PR quand le dépôt était privé (retirée avant le passage en public). |
| #4 | Médias HD servis depuis une copie R2. |
| #5 | Correctif « Voir les cartes », tris, profil privé `/moi`. |
| #6 | Vidéos dans la fiche et au survol. |
| #7 | Statistiques : comptes d'origine et totaux sur la chaîne. |
| #8 | Dex des 168 modèles, badges. |
| #9 | Badges par carte, affichés dans le Dex. |
| #10 | *Ouverte, en attente de test* : piste pour débloquer les comptes Rules d'origine via un ordre signé de la marketplace. |
| #11 | Prix de vente, ancien marché Cairo 0, historique d'un exemplaire, tirage max, C-Score, rareté Live, version anglaise. |
| #12 | *Fermée* : essai d'un fork de l'application React de Rules, abandonné au profit de la page HTML unique. |
| #13 | Interface au style Rules dans la page HTML. |
| #14 | Interface mobile. |
| #15 | Vidéo au survol dans le Dex. |
| #16 | Case Pack dans le Dex ; partie admin. |
| #17, #18 | Badges et cadre des cartes. |
| #19 | Icône de l'onglet. |
| suivante | Préparation du passage en public : nettoyage, documentation, page mentions légales. |
